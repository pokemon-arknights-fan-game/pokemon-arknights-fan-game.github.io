# PokeAPI 요약 자료

원본 저장소·고정 커밋·확인 날짜는 revision.json에 있습니다. pokemon_species.csv, pokemon_species_names.csv(한국어 language 3), pokemon_types.csv, types.csv, pokemon_stats.csv에서 전국도감 1~151의 기본형 정보를 추출했습니다. 이름·현재 타입·현재 종족값을 보존하며 진화 관계는 이번 범위 안의 연결만 남깁니다.

전체 세대 CSV나 이미지·도감 설명·기술 문구는 포함하지 않습니다. 원본 저작권·라이선스는 LICENSE.md에 보존했습니다. 한국어 이름과 포켓몬 관련 권리는 원 권리자에게 있습니다.
