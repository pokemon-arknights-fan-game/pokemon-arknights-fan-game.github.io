# 경로 이동·유닛 배치 프로토타입

## 방향과 현재 범위

명일방주 형태의 격자 배치·경로 방어를 중심으로, 포켓몬 타입 상성과 기술을 결합할 예정입니다. 장기적으로 섬멸작전 수준의 규모와 난이도를 목표로 합니다. 현재는 적 경로 이동과 지상·언덕별 유닛 배치를 구현했습니다. 지상형의 기본 저지 수 0~3과 적 정지를 지원합니다. 방향별 범위, 공격 간격, 공격력·HP와 사망 처리를 지원합니다. 손패 9장과 드래그 사용, 임시 범위 스킬을 지원합니다. 최종 카드별 스킬·타입 상성·웨이브는 아직 없습니다. 배치 상세 규칙은 [유닛 배치](deployment.md)를 참고합니다.

## 실행 규칙

- 적은 기본 1마리이며 준비 중 테스트용 1~4마리를 선택할 수 있습니다. 초기 기지 체력은 3이고 최소 0입니다.
- 준비 → 경로 안내 → 출현 준비 → 이동 중 → 도착 상태로 진행합니다. 시작은 준비 상태에서만 가능합니다.
- 시작 전에는 적과 경로 안내를 숨깁니다. 시작 후 약 1.5초간 경로를 그리고 지우며, 안내 레이어가 완전히 사라진 다음 프레임에 적이 출발점에 나타납니다. 저지되지 않은 적은 마지막 지점에 도착하면 사라지고 기지 체력을 1 감소시킵니다. 체력은 0 아래로 내려가지 않습니다. 모든 적이 처치되거나 도착하면 종료하며, 기지 체력이 0이 되어도 종료합니다.
- 속도는 기본 1칸/초이며 0.5·1·2칸/초를 실행 중에도 선택할 수 있습니다.
- 초기화는 예약된 프레임을 취소하고 위치·기지 체력·코스트·상태를 복구하며 모든 유닛 배치와 미리보기를 제거합니다. 속도 선택은 유지합니다.
- 숨겨진 문서의 시간은 경로 안내와 이동에 누적하지 않습니다. 보이는 동안에도 한 번에 반영할 시간을 최대 0.1초로 제한합니다. 큰 처리 지연이 발생하면 실시간보다 느리게 진행할 수 있습니다.

## 맵과 경로

현재 맵은 **임시 12열 × 8행**입니다. 공식의 공통 규격을 확인한 값이 아닙니다. 원작과 크기를 맞추는 것은 유지할 목표이며, 참조할 공식 스테이지를 정해 실제 행·열을 검증한 뒤 조정해야 합니다. 현재 맵과 경로는 독자적인 이동 확인용 구성입니다.

좌표는 왼쪽 위가 (0, 0)이고 오른쪽·아래 방향으로 증가합니다. 설정은 `src/scripts/prototype.js`의 `stageConfig`, 경로는 `route`에 있습니다. 경로는 가로 또는 세로 직선으로 연결되는 꺾임 지점 목록입니다. 출현 전 SVG 안내 선도 같은 경로 목록에서 생성합니다. 경로에 해당하는 타일 배경은 평소와 동일하며 계속 강조하지 않습니다. 지형은 `terrainRows`로 별도 정의하며, 적의 경로 칸은 지상입니다.

경로 지점은 서로 다른 맵 내부 정수 좌표여야 하고, 인접 지점끼리는 x 또는 y 하나만 달라야 합니다. 이번 정적 경로는 이 조건을 만족합니다. 자유 경로 편집 기능은 아직 없습니다.

## 코드 역할

| 함수 | 역할 |
| --- | --- |
| `createBattlefield` | 격자, 출발점·기지, 적과 SVG 안내 레이어 생성 |
| `renderRoutePreview` | 진행률에 따라 선 길이와 불투명도 반영 |
| `renderPrototype` | 체력, 상태, 버튼, 적의 화면 위치 반영 |
| `startGame` | 중복 시작을 막고 첫 프레임 예약 |
| `tick` | 경과 시간과 화면 갱신, 다음 프레임 예약 |
| `updateEnemy` | 적별 이동·접촉·저지와 다음 경로 지점 선택 |
| `handleEnemyArrival` | 도착 중복 방어와 체력 차감 |
| `resetGame` | 예약 취소 및 상태 복구 |

게임 위치는 칸 단위로 저장하고 화면 표시 시 전장 크기 대비 퍼센트로 변환합니다. 적의 위치와 원본 경로 좌표는 별도 객체입니다. 화면 크기 변경이 이동 속도에 영향을 주지 않습니다.

## 확인할 시나리오

- 시작 전 적·안내 숨김, 중복 시작 방지, 경로 안내 종료 후 출현, 경로의 모든 꺾임 통과
- 속도 변경 후 이동 시간 변화, 도착 후 체력 단일 차감
- 이동 중·도착 후 초기화, 다시 시작했을 때 정상 속도
- 다른 탭을 보다가 복귀했을 때 위치 도약 방지
- 작은 화면에서도 격자와 조작 영역이 화면 안에 표시됨

유닛 배치 변경 시에는 지형 일치·점유·유닛 중복 판정, 미리보기와 확정·취소, 작전 중 배치, 종료 시 미리보기 정리와 초기화를 함께 확인합니다.

## 출현 전 경로 안내

시간은 `stageConfig.routePreviewSeconds`로 관리하며 기본 1.5초입니다. 프레임 경과 시간을 누적해 앞 70% 동안 선을 그리고 다음 25% 동안 지운 뒤 마지막 5%는 투명하게 유지합니다. 안내 시간은 적 이동 거리로 소비하지 않습니다. 이동 속도 선택도 안내 시간에는 영향을 주지 않습니다.

SVG `pathLength`로 길이를 1로 정규화하고 `stroke-dashoffset`과 `opacity`를 제어합니다. 별도의 CSS 전환이나 타이머가 남아 출현 시점과 어긋나지 않도록 같은 프레임 루프에서 안내와 이동 단계를 제어합니다.

`spawning`에서는 레이어를 제거한 뒤 적은 숨긴 상태로 한 프레임을 보내고, 다음 프레임의 출발점에서 적을 표시합니다. 초기화하면 프레임 예약·누적 시간·레이어 표시를 함께 정리합니다. 유닛 배치와 미리보기는 안내 중에도 가능합니다.

동작 줄이기 설정에서는 선이 진행하며 그려지는 대신 정적인 경로를 같은 안내 시간 동안 표시하고 제거합니다. 안내가 끝나기 전에 적이 나타나지 않는 규칙은 동일합니다. 탭 숨김 시간과 긴 프레임 제한 때문에 실제 벽시계 기준 안내 시간은 늘어날 수 있습니다.

## 저지 수

현재 적은 `gameState.enemies` 배열로 관리합니다. `tick`이 각 적을 순서대로 갱신하므로 같은 프레임에 접촉해도 남은 저지 용량을 차례대로 소비합니다. 자세한 기본값과 접촉 규칙은 [저지 수](blocking.md)를 참고하세요.

실시간 전투 수치와 대상 선택·피해·사망 규칙은 [전투](combat.md)를 참고하세요.

DP 소환 비용과 회복, PP 최대치 확장은 [코스트](costs.md)에 정리합니다. 같은 게임 시간으로 안내·전투와 자원을 갱신합니다. PP는 카드를 회복 영역에 놓아 1 회복합니다.
