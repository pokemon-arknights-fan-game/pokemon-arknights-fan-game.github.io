# 지상형 유닛의 저지 수

## 기본 규칙

지상형의 `blockCount`는 동시에 저지할 수 있는 적의 최대 수입니다. 기본값은 정수 0~3이며, 0도 유효합니다. 언덕형은 적을 저지하지 않습니다. 기본 역할 수치는 테스트용이고 포켓몬 공식 속성이 아닙니다.

- 파이리 0, 모래두지 1, 이상해씨 2, 잠만보 3입니다.
- 저지 중인 적이 최대 수보다 적을 때만 새 적을 저지합니다.
- 용량이 찬 유닛이나 저지 0 유닛은 적을 막지 않습니다. 초과한 적은 다음 유닛이나 기지로 이동합니다.
- 배치 확정된 유닛만 저지합니다. 선택·미리보기만으로는 막지 않습니다.
- 방향은 저지 여부에 영향을 주지 않습니다.
- 저지된 적과 아군은 [전투 규칙](combat.md)에 따라 공격합니다. 적이 처치되면 슬롯을 반환하고 아군이 쓰러지면 적이 이동을 재개합니다. 철수와 스킬에 의한 일시 증가는 아직 없습니다.

## 접촉과 관계

유닛 칸 중심에서 가로·세로 각각 0.4칸 이내를 접촉 범위로 사용합니다. 이번 프로토타입의 판정이며 원작과 정확히 동일한 충돌 범위라는 의미는 아닙니다. 고속 이동도 현재 위치와 다음 위치 사이를 검사해 저지 지점을 건너뛰지 않게 합니다. 경로를 따라 먼저 만나는 저지 가능한 유닛을 선택합니다.

작전 중 적이 있는 칸에 배치하면 다음 이동 갱신에서 접촉 범위를 검사합니다. 이미 유닛을 지나간 적을 뒤로 끌어오지는 않습니다.

적마다 `blockedBy`에 저지 유닛 식별자를 기록하며, 미저지는 `null`입니다. 현재 저지 수는 적 목록에서 이 식별자가 일치하는 미도착 적을 세어 계산합니다. 적과 유닛 양쪽에 별도의 증가 카운터를 두지 않습니다. 같은 적은 한 유닛에만 속하고, 매 프레임 중복으로 슬롯을 소비하지 않습니다.

| 함수 | 책임 |
| --- | --- |
| `getBlockCapacity` | 지상형의 유효한 기본 저지 수 조회 |
| `getBlockedCount` | 유닛이 저지 중인 적 수 계산 |
| `canBlockEnemy` | 도착 여부·현재 관계·잔여 용량 확인 |
| `distanceToBlocker` | 직선 이동 구간에서 접촉까지의 거리 계산 |
| `updateEnemy` | 기존 저지 유지 또는 이동 중 새 저지 획득 |

초기화하면 적과 배치가 새로 생성되어 저지 관계가 전부 제거됩니다. 코드상 저지 유닛이 더 이상 존재하지 않으면 관계를 해제하고 이동을 재개하는 방어 처리가 있지만, 개별 철수 UI는 아직 없으며 아군 전투불능 시에도 이 관계를 명시적으로 해제합니다.

## 테스트 조작

준비 상태에서 **테스트 적 수**를 4마리로 선택하고 경로 첫 구간의 빈 지상 칸에 유닛 하나를 배치합니다. 시작하면 같은 경로로 4마리가 동시에 출현합니다. 이는 용량 검사용이며 시간차 웨이브 시스템이 아닙니다. 기본 적 수는 1마리입니다. 적 수는 작전 시작 후 변경할 수 없고 초기화 시 현재 선택값을 유지합니다.

최초 접촉에서 정지할 수 있는 적은 각각 0·1·2·3마리이며 나머지는 통과합니다. 현재는 전투도 진행되므로 처치와 아군 사망에 따라 이후 현재 저지 수가 달라집니다. 카드와 맵의 배지는 `현재 / 최대`를 표시하고 상단에는 전체 저지 수를 표시합니다. 저지된 적은 붉은색으로 구분합니다. 적 도착 수는 전체 테스트 적 수를 기준으로 표시합니다.

기지 체력은 0에서 더 내려가지 않으며 0이 되면 상태 문구로 방어 실패를 표시합니다. 모든 적이 처치되거나 도착하면 종료합니다. 기지 체력 0도 종료 조건입니다.
