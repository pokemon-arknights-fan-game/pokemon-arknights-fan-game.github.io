# 화면 자동 맞춤

게임은 브라우저의 현재 보이는 영역(100dvh)을 채웁니다. 창 크기와 모바일 방향 변화에 자동 대응하므로 해상도를 직접 선택할 필요가 없습니다.

- 상단 상태와 카드 사용 영역, 가운데 전장, 하단 손패로 나눕니다.
- 12×8 전장은 ResizeObserver가 컨테이너의 남은 가로·세로 공간을 읽어 정사각형 칸을 유지하도록 축소·확대합니다.
- 작은 세로 화면에서는 손패를 3×3으로 배치합니다. 가로 화면과 데스크톱에서는 한 줄에 표시합니다.
- 카드 사용 영역은 카드 선택 중 실제 맵 위에 absolute 레이어로 겹쳐 표시합니다. 선택 전후 맵의 위치·크기는 동일합니다. 좌측 스킬·우측 소환은 구형 표시와 주변 사각형 전체를 드롭 대상으로 사용하며, PP 회복은 중앙 상단에 있습니다. 사용 방법을 정하면 레이어가 사라져 맵 전체에서 위치를 고를 수 있습니다. 영역 밖에 놓으면 취소됩니다.
- 선택 정보와 키보드용 방향·확정 조작은 도움말로 옮겼으며, 긴 상태도 도움말에서 전체 문장을 확인할 수 있습니다. 좁은 화면의 카드 상세 정보도 해당 카드를 선택한 뒤 도움말에서 확인할 수 있습니다.
- 전체 화면 버튼은 지원하는 브라우저에서 사용자 클릭으로 실행합니다. Esc 또는 종료 버튼으로 돌아옵니다. 브라우저 전체 화면을 사용하지 않아도 화면 맞춤은 동작합니다.

페이지와 손패 자체에는 스크롤이 없습니다. 긴 도움말과 묘지 목록은 별도의 창 안에서 스크롤할 수 있습니다. 화면을 극단적으로 줄이면 표시 크기도 작아지므로 모바일에서는 가로·세로 방향 중 편한 쪽을 선택하세요.

관련 코드: index.html, src/styles/prototype.css, src/scripts/viewport.js. 입력 좌표는 card-input.js에서 현재 전장 사각형을 기준으로 계산합니다.
