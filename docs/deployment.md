# 유닛 배치

## 조작

하단 손패를 오른쪽 배치 영역으로 드래그 → 맵 칸 누르기 → 방향으로 드래그 → 놓기 순서로 조작합니다. 선택 정보는 전장 옆에 표시하며 작은 화면에서는 전장 아래로 이동합니다. 명일방주의 카드 선택·유효 칸 강조·방향 선택 흐름을 참고한 프로토타입 UI입니다. 마우스·터치 포인터 드래그를 사용하며, 키보드에는 기존 방향·확정 버튼을 제공합니다. [카드 조작](cards.md)을 참고하세요.

- 준비 중, 경로 안내 중과 작전 중에 배치할 수 있습니다.
- 카드를 배치 영역에 놓으면 허용된 빈 칸을 초록색으로 강조합니다.
- 칸을 누르면 반투명 유닛으로 미리보기하며, 기본 방향은 오른쪽입니다.
- 위·아래·왼쪽·오른쪽을 선택한 뒤 확정합니다. 방향에 따라 격자 공격 범위를 회전합니다. 주황색 테두리가 인식 범위입니다.
- 선택 취소 또는 Esc로 임시 선택을 지웁니다. 다른 카드로 바꾸어도 이전 미리보기는 사라집니다.
- 배치에 사용한 카드는 필드로 이동하고 가능한 만큼 손패가 보충됩니다. 같은 포켓몬이 이미 배치되어도 다른 카드 개체로 스킬·PP 회복은 가능합니다. 아군을 선택하고 퇴각 버튼으로 철수할 수 있으며 카드는 묘지로 이동합니다.

## 규칙과 임시 유닛

| 유닛 | 배치 유형 | 기본 최대 저지 수 |
| --- | --- | --- |
| 이상해씨 | 지상형 | 2 |
| 파이리 | 지상형 | 0 |
| 모래두지 | 지상형 | 1 |
| 잠만보 | 지상형 | 3 |
| 피카츄 | 언덕형 | 0 (저지 불가) |
| 꼬부기 | 언덕형 | 0 (저지 불가) |

이는 프로토타입의 임시 역할 분류이며 포켓몬 공식 속성이나 최종 전투 역할을 뜻하지 않습니다. 그림은 문자 토큰으로 표시합니다.

지상형은 지상 칸, 언덕형은 ▴로 표시한 언덕 칸에만 배치합니다. 출발점·기지·× 표시 칸에는 배치할 수 없습니다. 한 칸에는 한 유닛, 유닛별 한 번만 배치할 수 있습니다. 여섯 유닛을 각각 한 번 배치할 수 있으며 유닛별 DP 비용을 소비합니다. 부족하면 배치할 수 없습니다. 비용은 [코스트](costs.md)를 참고하세요.

적의 이동 경로와 지형은 별도 데이터입니다. 일반 경로 칸에는 지상형 배치가 가능합니다. 지상형은 기본 최대 저지 수만큼 적을 멈추며, 용량이 찼거나 저지 수가 0이면 통과합니다. **저지된 적과 아군은 공격 간격에 따라 교전합니다. 적 처치 시 슬롯이 반환되고 아군이 쓰러지면 저지가 해제됩니다.** 작전 종료 시 미리보기를 취소하고 추가 배치를 막습니다. 초기화는 적 이동과 확정 배치, 미리보기 모두 정리합니다.

## 데이터와 함수

구현은 `src/scripts/prototype.js`에 있습니다.

| 이름 | 역할 |
| --- | --- |
| `terrainRows`, `stageTiles` | G=지상, H=언덕, X=배치 불가 지형 |
| `units` | 식별자·이름·배치 유형·토큰 색상 |
| `selectedUnitId` | 현재 선택한 카드 |
| `pendingPlacement` | 미확정 칸 좌표와 방향 |
| `placements` | 확정한 유닛 식별자·좌표·방향 목록 |
| `getPlacementError` | 게임 상태·지형·점유·중복 판정, 허용 시 빈 문자열 |
| `selectUnit`, `selectDeploymentTile` | 선택 및 미리보기 |
| `confirmPlacement`, `cancelPlacement` | 판정 재확인 후 확정 또는 취소 |
| `renderDeployment` | 카드·칸·방향·배치 수·안내 표시 |

화면 강조와 실제 확정은 같은 판정 함수를 사용합니다. 카드와 칸은 부모 리스너의 이벤트 위임과 `dataset`으로 식별합니다. 각 칸은 좌표·지형·배치 상태를 설명하는 이름이 있는 버튼이므로 키보드 선택도 가능합니다.

## 확인 기준

1. 지상형 선택 시 언덕과 예약 칸이 강조되지 않습니다. 언덕형도 반대 지형을 선택할 수 없습니다.
2. 확정 전에는 배치 수가 늘지 않습니다. 방향 변경과 취소도 배치 수를 바꾸지 않습니다.
3. 이미 배치된 유닛이나 점유된 칸에 추가 배치할 수 없습니다.
4. 작전 중에도 배치할 수 있고, 접촉 범위에 있는 적은 다음 이동 갱신에서 저지됩니다.
5. 작전 종료 시 미리보기가 정리되며 초기화 후 같은 유닛을 다시 배치할 수 있습니다.
6. 작은 화면에서 가로 넘침 없이 조작하고 Tab·Enter·Space·Esc로도 선택·취소할 수 있습니다.

저지 판정과 테스트 방법은 [저지 수](blocking.md)를 참고하세요.

배치된 유닛을 누르면 현재 HP와 범위를 확인할 수 있습니다. 전투불능·퇴각 카드는 묘지 순환 후 다시 뽑으면 최대 HP로 재배치할 수 있습니다. [전투 규칙](combat.md)을 참고하세요.
