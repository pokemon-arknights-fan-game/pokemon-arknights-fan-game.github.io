# 손패와 드래그 카드 사용

## 조작 흐름

손패를 누르는 즉시 게임이 0.2배속이 됩니다. 별도의 길게 누르기 대기 시간은 없습니다. 카드의 이동 표시는 원본 카드와 분리해 포인터를 따라갑니다.

| 놓는 곳 | 결과 |
| --- | --- |
| 중앙 상단 PP 회복 영역 | 카드 1장을 소모해 PP 1 회복 |
| 왼쪽 스킬 영역 | 맵에서 사용할 범위 선택 시작 |
| 오른쪽 배치 영역 | 맵에서 배치 위치·방향 선택 시작 |
| 세 영역 바깥 | 취소, 카드·코스트 유지 |

제시된 세 사용처 외의 네 번째 선택은 취소로 해석합니다. 사용 영역에 놓은 뒤 위치를 결정하는 동안에도 0.2배속을 유지하고 최종 사용·실패·취소에서 정상 속도로 복구합니다.

### 스킬

스킬 영역에 카드를 놓으면 맵으로 이동해 범위를 고를 수 있습니다. 포인터를 움직이면 중심 포함 3×3 범위를 미리 보여줍니다. 맵을 누른 채 다른 위치로 끌어 중심을 바꾸고, 놓는 순간 해당 위치에 스킬을 사용합니다. 맵 밖에서 놓으면 취소합니다.

### 배치

배치 영역에 카드를 놓은 뒤에는 포인터 이동으로 후보 칸을 바꿀 수 있습니다. 원하는 칸을 누르면 그 칸이 고정됩니다. 누른 채 상하좌우로 끌면 공격 방향을 미리 보여주고, 맵 안에서 놓으면 해당 칸·방향으로 배치합니다. 방향 드래그 중에는 위치를 옮기는 대신 방향을 결정합니다. 드래그가 10px 미만이면 기본 오른쪽 방향입니다.

지형·점유·같은 포켓몬 동시 1기·DP 조건을 최종 확정 시 재검사합니다. 실패하면 비용과 카드를 유지합니다. 퇴각·전투불능 카드는 순환 후 다시 뽑으면 재배치할 수 있습니다.

### 취소와 대체 조작

Esc, 화면 위 취소 버튼, 선택 취소 버튼으로 취소할 수 있습니다. 포인터 취소·캡처 손실·창 전환·탭 숨김·초기화·작전 종료도 선택과 캡처를 정리합니다. 취소된 제스처의 늦은 놓기 이벤트로 새 카드가 사용되지 않아야 합니다.

키보드는 카드에서 Enter/Space → 사용 영역 선택 → 맵 칸 선택으로 진행합니다. 스킬은 칸 활성화 시 사용하고, 배치는 방향 버튼과 배치 확정 버튼을 사용합니다. 모바일 손패는 좌우 화살표로 넘겨 볼 수 있습니다. 카드·맵에서의 터치 드래그는 브라우저 스크롤 대신 게임 조작을 사용합니다.

## 손패·묘지·덱

선택한 40장 덱을 섞어 고정 손패 9장을 뽑고, 사용 후에도 9장으로 보충합니다. 스킬·PP 회복은 묘지로 이동하며 배치는 필드로 이동합니다. 필드 카드는 퇴각·전투불능 시에만 묘지로 갑니다. 빈 덱은 묘지를 섞어 회수하고 손패를 가능한 만큼 보충합니다. 필드에 카드가 남아 뽑을 수 없으면 손패는 9장보다 적거나 0장일 수 있습니다. 카드의 instanceId는 재순환해도 유지합니다. 취소·가득 찬 PP·비용 부족에는 이동이 없습니다.

자세한 편성·저장·퇴각 규칙은 [덱 시스템](decks.md)을 참고하세요.

## PP와 임시 스킬

회복량은 카드 1장당 PP +1로 임시 설정합니다. 현재 PP가 최대치와 같으면 회복용 소모를 거부합니다. 최대치 확장이나 자동 회복 규칙은 [코스트](costs.md)를 참고하세요.

모든 임시 스킬은 PP 1을 소비하며 같은 3×3 범위를 사용합니다. 카드별 상세 구현 전의 테스트 효과입니다.

| 카드 | 임시 스킬 | 효과 |
| --- | --- | --- |
| 이상해씨 | 생명의 빛 | 아군 HP +3, 최대 HP까지 |
| 파이리 | 불꽃 파동 | 범위 안 출현한 적에게 즉시 피해 4 |
| 모래두지 | 모래 파동 | 범위 안 출현한 적에게 즉시 피해 3 |
| 잠만보 | 응원 | 아군 공격 +1, 게임 시간 5초 |
| 피카츄 | 전기 파동 | 범위 안 출현한 적에게 즉시 피해 4 |
| 꼬부기 | 회복의 물결 | 아군 HP +4, 최대 HP까지 |

강화는 중첩하지 않고 다시 사용하면 +1과 5초를 갱신합니다. 범위가 비어 있어도 유효한 맵 위치에 사용하면 카드·PP를 소비합니다. 출현 전 숨겨진 적은 피해 대상으로 보지 않습니다. 피해로 적이 처치되면 일반 공격과 동일하게 저지·종료를 정리합니다.

## 시간과 구조

슬로우는 이동뿐 아니라 공격 간격·경로 안내·DP 회복·PP 최대치 확장·강화 지속 시간에 함께 적용합니다. UI 포인터와 카드 이동은 정상 속도입니다. 숨겨진 탭에서는 기존대로 게임 시간이 멈춥니다.

- `card-input.js`: 포인터 ID·캡처·화면 좌표·영역/칸 판정·방향 드래그, 코어 콜백 호출.
- `prototype.js`: 손패·묘지·사용 상태, 비용 재검사, 효과 반영, 보충과 게임 시간.
- `getTimeScale`: 선택 상태에서 시간 배율 계산.
- `consumeHandCard`: 개체 재검사 후 원본 기록과 같은 슬롯 보충.
- `beginCardAction → chooseCardMode → setCardTarget → commitCardTarget`: 단계별 사용 흐름.
- `cancelCardAction`: 중단 경로의 공통 정리.

확인할 항목은 마우스·터치·키보드 사용, PP 가득 참 거부, 스킬 범위 이동, 방향 드래그, 전체 카드 수 보존·ID 유일성·필드/묘지 기록, 비용 중복 차감 방지와 모든 중단 경로의 정상 속도 복구입니다.
