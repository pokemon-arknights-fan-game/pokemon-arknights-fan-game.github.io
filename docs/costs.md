# DP·PP 코스트

## 이번 범위

DP는 소환용, PP는 스킬용 자원입니다. DP는 배치 확정 시 소비하고, PP는 손패 1장을 회복 영역에 놓아 1 회복한 뒤 임시 스킬에 1 소비합니다. 자세한 제스처와 손패 규칙은 [카드 사용](cards.md)을 참고하세요.

## 규칙

| 항목 | DP | PP |
| --- | --- | --- |
| 용도 | 유닛 소환 | 향후 스킬 사용 |
| 초기 현재량 | 10 (임시) | 0 (임시) |
| 초기 최대치 | 99 | 1 |
| 시간에 따른 변화 | 게임 시간 1초마다 현재량 +1 | 게임 시간 60초마다 최대치 +1 |
| 최종 최대치 | 99 | 10 |
| 현재량 자동 회복 | 있음 | 없음 |

초기 DP 10과 현재 PP 0은 미정 항목에 대한 프로토타입 값이며 `costConfig`에서 조정합니다. PP 최대치가 1에서 2로 늘어도 현재 PP는 그대로입니다. 처음부터 진행하면 PP 최대치는 60초에 2, 120초에 3, 540초에 10이 됩니다. 이후 더 늘어나지 않습니다.

PP가 가득 차면 손패를 회복용으로 소모할 수 없습니다. 회복 영역에 놓아도 카드·묘지·손패 개수가 변하지 않으며 선택을 취소하고 정상 속도로 돌아갑니다.

## 시간 정책

작전 시작 후 경로 안내·출현 준비·전투 중 흐르는 게임 시간을 사용합니다. 준비 화면과 종료 후에는 회복·최대치 증가가 멈춥니다. 숨겨진 탭의 시간도 누적하지 않습니다. 기존 프레임 상한에 따라 처리 지연이 크면 벽시계 시간보다 느리게 진행할 수 있습니다. 이동 속도 선택은 자원 시간에 영향을 주지 않습니다.

프레임의 소수 시간을 누적하고 완료된 주기만 반영합니다. DP 99에서 회복을 계속 비축하지 않으며, 가득 찬 뒤 소비하면 새로 1초를 모아야 다음 DP가 들어옵니다. PP 최대치 10에서는 확장 시간을 더 쌓지 않습니다. DP가 가득 차도 PP 최대치 확장은 계속 진행합니다.

현재 단일 짧은 스테이지는 1분 전에 끝날 수 있어 PP 확장을 실제 플레이에서 보기 어려울 수 있습니다. 최대치 로직은 시간 경계 검사로 별도 검증합니다. 시간 건너뛰기나 무료 PP 충전 버튼은 없으며 실제 회복은 카드 소모만 사용합니다.

## 소환 비용

| 유닛 | DP 비용 (임시) |
| --- | --- |
| 이상해씨 | 3 |
| 파이리 | 4 |
| 모래두지 | 3 |
| 잠만보 | 6 |
| 피카츄 | 5 |
| 꼬부기 | 4 |

카드에 DP 비용을 표시하고, 부족한 카드는 색으로 구분합니다. 부족해도 카드를 선택해 설명을 볼 수 있지만 배치 가능한 칸은 강조되지 않고 확정할 수 없습니다. DP가 회복되면 강조·확정 가능 여부가 갱신됩니다.

비용은 성공적인 배치 확정 시에만 한 번 소비합니다. 카드 선택·칸 미리보기·방향 변경·취소·배치 실패에는 소비하지 않습니다. 배치 성공 시 선택한 카드 개체도 묘지로 이동하고 손패가 보충됩니다. 확정 직전에 잔액과 지형·점유·중복을 다시 확인합니다. 전투불능 시 DP 환급은 없습니다.

초기화하면 DP·현재 PP·PP 최대치와 두 자원의 누적 시간이 초기값으로 돌아옵니다. 적 수 변경은 자원 상태를 초기화하지 않습니다.

## 코드 연결과 확인

- `costConfig`: 초기량·최대치·주기 설정.
- `createCostState`: 자원의 현재량과 누적 시간 초기화.
- `updateCosts`: DP 회복과 PP 최대치 증가.
- `getPlacementError`: 배치 조건과 DP 부족 판정.
- `confirmPlacement`: 재검사 후 DP 차감과 배치.

1초·60초 직전과 직후, 99·10 상한, 현재 PP 불변, 초기화와 탭 숨김, 비용과 잔액이 정확히 같은 배치, 중복 확정과 취소를 확인합니다.

카드 선택 중에는 DP·PP 최대치 시간도 다른 게임 시스템과 함께 0.2배속입니다. PP 회복 자체는 유효한 드롭 시 즉시 처리합니다.
