# 1세대 151종 카드 데이터

## 구성과 사용

- data/pokemon-gen1.js: 전국도감 001~151의 카드 정의 및 등급 규칙
- data/training-deck.js: 현재 프로토타입에 순환 공급할 카드 ID 목록
- data/source/pokeapi/: 고정된 출처·151종 요약 자료·원본 라이선스
- scripts/build-pokemon-cards.py: 외부 통신 없이 카드 데이터를 재생성
- scripts/check-pokemon-cards.mjs: 151종·등급 수·진화 순서·전투 필드 검증

최초 기본 덱은 훈련 포켓몬을 우선 넣고 다른 종류를 더해 40장을 구성합니다. 실제 덱은 카드 메뉴에서 보유 카드로 편성하고 전투 입장 시 선택합니다. 동일 포켓몬의 여러 손패 개체는 instanceId로 구분합니다. 보유 카드·덱 편성 UI를 지원하며 뽑기와 진화 실행 기능은 아직 없습니다.

## 등급 배분

151에 목표 비율을 곱하면 60.4 / 45.3 / 30.2 / 15.1입니다. 정수 부분을 먼저 배분하고 남은 1장을 소수 부분이 가장 큰 브론즈에 부여했습니다.

| 등급 | 수량 | 실제 비율 | 목표 |
|---|---:|---:|---:|
| 브론즈 | 61 | 40.40% | 40% |
| 실버 | 45 | 29.80% | 30% |
| 골드 | 30 | 19.87% | 20% |
| 레전드 | 15 | 9.93% | 10% |

최소 등급은 1세대 안에서의 진화 깊이로 결정합니다. 이후 레전드→골드→실버 순으로 필요한 수량을 승급합니다. 후보는 전설·환상 여부, 원작 종족값 합계 내림차순, 도감 번호 오름차순으로 정렬합니다. 자식 카드의 등급보다 낮게만 승급할 수 있습니다. 따라서 모든 진화 간선에서 부모보다 자식 등급이 높습니다. 이브이의 세 갈래 진화도 각각 검사합니다.

레전드 15종: 이상해꽃, 리자몽, 거북왕, 윈디, 파르셀, 나시, 갸라도스, 라프라스, 잠만보, 프리져, 썬더, 파이어, 망나뇽, 뮤츠, 뮤.

이 비율은 **전체 카드 종류의 분포**이며 뽑기 확률은 아닙니다. 등급별 획득 확률·진화 조건·보유 제한은 아직 구현하지 않았습니다.

## 필드와 임시 전투 수치

카드에는 id, dexNumber, name, types, rarity, evolvesFrom/evolvesTo, evolutionStage와 함께 기존 엔진용 dpCost, attack, maxHp, attackInterval, terrain, blockCount, rangeId, skill이 있습니다. 실제 좌표 범위는 prototype.js의 melee/flame/ranged 템플릿으로 연결합니다.

일반 카드의 임시 역할은 비행·에스퍼·전기·얼음·고스트, 일부 물 타입을 언덕형으로 분류합니다. 나머지는 지상형이며 방어·체력에 따라 저지 수를 1~3으로 배정하고 불꽃 지상형은 저지 0을 사용합니다. 이는 이 팬게임의 역할이며 원작 설정이 아닙니다.

공격력은 원작 공격·특수공격 중 큰 값과 등급으로, HP는 원작 HP·방어와 등급으로 산정합니다. 공격 간격은 스피드에 따라 0.8/1/1.2초, DP는 등급·공격력·저지·지형으로 산정합니다. 정확한 산식은 생성 스크립트에 있습니다. 기존 이상해씨·파이리·모래두지·잠만보·피카츄·꼬부기는 기존 전투 수치·스킬을 유지합니다.

스킬은 현재 지원되는 피해·회복·공격 버프 중 하나입니다. 모두 PP 1과 중심 포함 3×3 범위를 사용하고 버프는 5초·중첩 없이 갱신합니다. 임시 스킬명과 효과는 원작 기술 재현이 아닙니다. 타입 정보는 준비만 하며 타입 상성 피해 계산은 아직 추가하지 않습니다.

## 출처와 세대 기준

종 목록은 1세대 출신 151종이며 타입·종족값은 고정한 PokeAPI 리비전의 현재 값을 사용합니다. 예: 코일의 강철 타입, 삐삐의 페어리 타입을 포함합니다. 적·녹 당시 타입 규칙이 아닙니다. 피츄 등 2세대 이후 진화 전·후 종은 이번 진화 관계에 포함하지 않습니다.

이름·타입·진화 관계·원작 종족값의 출처는 [PokeAPI 공개 CSV](https://github.com/PokeAPI/pokeapi/tree/2bf639e5572812a67d2b94903fdcb9d095f5aeb2/data/v2/csv)입니다. 이 값과 프로젝트에서 만든 임시 밸런스 수치를 구분합니다. 출처 라이선스는 data/source/pokeapi/LICENSE.md에 보존합니다. 실행 중 외부 API를 호출하지 않습니다.

## 검증·재생성

```powershell
python scripts/build-pokemon-cards.py
node scripts/check-pokemon-cards.mjs
```

생성 파일을 직접 고치면 재생성 시 덮어씁니다. 밸런스를 변경하려면 생성 스크립트의 산식이나 OVERRIDES를 바꾼 뒤 검증하세요.
