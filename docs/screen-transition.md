# 화면 전환 효과

로비·전투 이동 시 전 화면을 불투명한 덮개로 가립니다. 중앙 문양과 회전 링만 표시하고 로딩 문구는 표시하지 않습니다. 보조 기술에는 화면 전환 중임을 알립니다.

1. 180ms 동안 덮개를 표시하며 요청을 시작합니다. 기존 화면의 실행은 즉시 정리하되 마크업은 덮개가 완전히 가릴 때까지 유지합니다.
2. 덮기와 요청이 모두 끝나면 HTML 교체와 mount를 실행합니다.
3. 두 프레임 동안 레이아웃 반영을 기다린 뒤 220ms 동안 덮개를 걷습니다.

전환 중 화면과 공통 도구 모음은 inert로 클릭·키보드 입력을 차단합니다. 완료 후 현재 화면의 제목 또는 오류 화면 버튼으로 포커스를 복구합니다. 빠른 해시 이동은 요청 번호와 애니메이션 세대로 구분합니다. 이전 전환이 새 덮개를 숨기지 못하게 합니다.

HTTP 실패 시에도 오류·재시도 화면을 준비한 뒤 덮개를 걷습니다. 응답이 없는 요청은 15초 후 취소해 오류 화면으로 전환합니다. 전체 화면은 공통 문서에서 계속 유지됩니다. prefers-reduced-motion에서는 페이드 시간을 0으로 하고 회전을 멈춥니다.

관련 코드: index.html의 screen-transition, src/styles/shell.css, src/scripts/screen-transition.js, src/scripts/shell.js.
