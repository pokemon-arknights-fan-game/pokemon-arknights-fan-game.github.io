# 메인 로비와 화면 연결

- index.html: 공통 화면 틀입니다. src/screens/lobby.html을 읽어 첫 화면으로 표시합니다.
- #battle: 기존 프로토타입 전투 영역입니다. 로비의 전투 링크로 입장합니다. battle.html은 호환 진입점입니다.
- 카드: 보유 카드 → 덱 편성 → 목록 → 새 덱·기존 덱 수정으로 연결합니다.
- 전투: 덱 선택 후 프로토타입에 입장합니다.
- 뽑기: 준비 중인 비활성 메뉴입니다.
- 전투 상단의 로비 링크로 돌아올 수 있습니다. 이동하면 진행 중인 전투는 종료됩니다. 저장·이어하기 기능은 없으며 전투 재입장 시 초기 상태로 시작합니다.

해시 링크로 한 문서 안의 화면 영역을 전환합니다. 별도 서버 설정 없이 GitHub Pages와 로컬 파일에서 사용합니다. 로비에서는 전투 DOM과 전투 상태를 생성하지 않습니다. 전투 페이지를 직접 열어도 기존 게임을 사용할 수 있습니다.

로비 스타일은 src/styles/lobby.css, 전투 스타일은 src/styles/prototype.css로 분리합니다. 같은 탭에서 이동하며 키보드로 전투 링크를 선택해 Enter로 입장할 수 있습니다. 준비 중인 메뉴는 실행되지 않습니다.

공통 전체 화면과 새 화면 등록 방법은 [공통 화면 틀](shell.md)을 참고하세요.
