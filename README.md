# Pokémon × 명일방주 웹 팬게임

포켓몬과 명일방주의 시스템을 혼합한 비공식 웹 팬게임 프로젝트입니다.
현재는 손패 드래그 사용, 지상·언덕 유닛 배치, 저지와 실시간 전투를 지원하는 초기 프로토타입을 제공합니다.

## 폴더 구조

```text
.
├── index.html       # 공통 화면 틀 / GitHub Pages 진입 페이지
├── lobby.html       # 로비 호환 진입점
├── battle.html      # 전투 호환 진입점
├── assets/          # 이미지, 오디오 등 정적 리소스
│   ├── images/      # 이미지 리소스
│   └── audio/       # 오디오 리소스
├── src/             # 게임 소스 코드
│   ├── screens/     # 로비·전투 HTML 조각
│   ├── scripts/     # JavaScript 코드와 화면별 모듈
│   └── styles/      # CSS 스타일
├── data/            # 게임 데이터
└── docs/            # 기획 및 개발 문서
```

각 폴더의 `README.md`에 용도를 정리합니다. 프레임워크와 빌드 도구 없이 HTML, CSS, JavaScript로 구성합니다.

## 로컬 확인

프로젝트 루트의 터미널에서 로컬 서버를 실행합니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 **http://localhost:8000**을 엽니다. 종료는 `Ctrl+C`입니다. Python이 없다면 IDE의 정적 웹 서버를 사용해도 됩니다. `file://`로 파일을 직접 여는 방식은 지원하지 않습니다. GitHub Pages에서는 별도 서버 실행 없이 동작합니다.

첫 화면은 로비입니다. 로비·전투는 iframe 없이 한 문서 안에서 전환합니다. 상단 공통 **전체 화면** 버튼은 모든 화면에서 사용할 수 있으며 로비·전투 이동 중에도 유지됩니다. 새로고침이나 탭 종료 후 자동 복원은 하지 않습니다. **전투**를 누르면 기존 프로토타입으로 이동합니다. **카드·뽑기**는 준비 중인 비활성 메뉴입니다. 전투 상단의 **로비**로 돌아오면 현재 전투는 종료되며 다시 입장할 때 초기 상태로 시작합니다.

1. 손패 9장과 DP 10, PP 0/1에서 시작합니다.
2. 카드를 누른 채 중앙 PP 회복·왼쪽 스킬·오른쪽 배치 영역 중 하나로 끌어 놓습니다. 선택 중에는 게임이 0.2배속입니다.
3. PP 회복은 카드 1장당 +1이며, 가득 찼다면 카드가 소모되지 않습니다.
4. 스킬은 맵에서 누른 채 범위를 이동하고 놓으면 사용합니다. 임시 비용은 PP 1입니다.
5. 배치는 원하는 맵 칸을 누른 뒤 방향으로 끌어 놓으면 DP와 카드를 소비합니다. Esc·영역 밖 놓기로 취소합니다.
6. 사용한 카드는 묘지로 이동하고 새 카드가 즉시 보충되어 손패는 9장을 유지합니다. 현재 덱은 훈련용 무한 순환 공급입니다.
7. **작전 시작** 후 경로 안내가 사라지면 적이 출현합니다. 유닛이 저지·공격하며 전체 적 처치·도착 또는 기지 체력 0에서 종료합니다.
8. DP는 게임 시간 초당 1씩 최대 99까지 회복하고 PP 최대치는 분당 1씩 최대 10까지 확장됩니다. 카드 선택 중에는 이 시간도 느려집니다.
9. **초기화**하면 배치·전투·코스트·손패·묘지가 초기화됩니다. 키보드 사용은 카드와 사용 영역을 선택한 뒤 맵 칸·방향·확정 버튼으로 진행합니다.

구현 범위와 임시 맵 규격은 [프로토타입 문서](docs/prototype.md), 배치 규칙은 [유닛 배치 문서](docs/deployment.md), 저지 판정과 테스트 방법은 [저지 수 문서](docs/blocking.md)를 참고하세요. 능력치와 전투 규칙은 [전투 문서](docs/combat.md), 자원은 [코스트 문서](docs/costs.md), 제스처·손패·임시 스킬은 [카드 사용](docs/cards.md)에 정리했습니다.

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment**에서 다음과 같이 설정합니다.

- Source: **Deploy from a branch**
- Branch: 배포할 브랜치 선택
- Folder: **/ (root)**

루트의 `index.html`을 진입점으로 사용하며 별도 빌드 과정은 없습니다.
실제 Pages 설정은 GitHub에서 별도로 진행해야 합니다.

## 프로젝트 안내

이 프로젝트는 비공식 팬 프로젝트이며 원작 권리자와 관련이 없습니다.
포켓몬 및 명일방주 관련 명칭과 원작 리소스의 권리는 각 권리자에게 있습니다.
